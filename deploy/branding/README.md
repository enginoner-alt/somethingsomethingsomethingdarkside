# Login page logo

Put your logo here as `logo.svg` (best), `logo.png` or `logo.webp`. The login
page keeps a space of 1943 x 432 proportions for it and scales the image to
fit. Without a file the space stays empty.

The folder is mounted read-only into the api container; after adding or
changing the file, reload the login page (it is cached for 5 minutes).
